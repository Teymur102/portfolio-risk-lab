# Portfolio Risk Lab

Do optimised portfolios beat simple ones out of sample, and which VaR model survives 2008 and 2020? No strategy's Sharpe is statistically different from equal weight or 60/40, and filtered historical simulation is the only 99% VaR model that passes Kupiec and is never in the Basel red zone.

## Results

Walk-forward 2007-12-03 to 2026-09-30, net of 10 bps costs; VaR on a 60/40 portfolio, 5,287 forecasts ([`results/tables.md`](results/tables.md)):

| Metric | Value |
|---|---|
| Best Sharpe: Max Sharpe vs 60/40 vs equal weight | 0.63 / 0.58 / 0.43 |
| Max Sharpe vs equal weight: Sharpe diff, 95% bootstrap CI, p | +0.19 [-0.17, +0.54], p = 0.28 |
| Max Sharpe annual turnover | 238% |
| Max drawdown: min variance vs 60/40 | -17.4% vs -35.2% |
| 99% VaR exceptions / expected: filtered HS, historical sim, normal | 61 / 53, 92 / 53, 144 / 53 |
| Filtered HS: Kupiec p, Basel windows green / yellow / red | 0.273, 84% / 16% / 0% |

## Proof

- **17 tests** (`pytest`): risk contributions and risk parity, min-variance closed form, max-Sharpe tangency, Ledoit-Wolf, HS/normal VaR and ES, EWMA recursion, Kupiec on a hand-computed case, Christoffersen, Basel zones, Sharpe tests.
- **One command:** `make` builds the venv, runs `run.py` (about 12 seconds) and the tests.
- **Data:** daily adjusted ETF closes from Yahoo Finance via [`yfinance`](https://github.com/ranaroussi/yfinance); risk-free rate FRED [DTB3](https://fred.stlouisfed.org/series/DTB3). Both cached in `data/`.
- **Deterministic:** fixed sample end date 2026-09-30 and a fixed bootstrap seed; rerunning reproduces every result file (only the recorded runtime changes).
- **Out-of-sample protocol:** monthly rebalances use only the trailing 756 days known at that close; each VaR forecast for day t uses data through t-1 only.

## Stack

Python 3.14 · numpy 2.5.4 · pandas 3.1.0 · scipy 1.18.1 · matplotlib 3.11.2 · yfinance 1.7.0 · pytest 9.2.0

## Run

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run.py && .venv/bin/python -m pytest -q
```

## Structure

```
prl/data.py       download and cache prices and T-bill rate
prl/optimize.py   Ledoit-Wolf, min variance, max Sharpe, risk parity
prl/backtest.py   walk-forward monthly rebalancing with drift and costs
prl/metrics.py    performance metrics, block bootstrap, Jobson-Korkie-Memmel
prl/var.py        HS / normal / EWMA / filtered HS VaR and ES; Kupiec, Christoffersen, Basel
tests/            core math tests
results/, figures/ generated by run.py
```
